# dc-cp1-microclips

Micro-clips for the **CP1 Lumbar + SI 15-Second Reel**
(`dc-cp1/cp1-lumbar-si-15sec-reel.html`).

Each file is ~22-26 seconds cut from the full CP1 demo video on R2 — the moment the
procedure is actually **performed**, not the lecture around it. Start points were chosen by
transcribing every source clip (Groq whisper-large-v3) and reading for contact / direction /
end-range language.

Clips are **re-encoded**, not stream-copied, so each opens on a keyframe and the page can
play it from `t = 0`. A seek offset against an already-cut file lands at the end of the clip
instead of the demo.

`cp1-NNN.mp4` matches the procedure's `snum` in the CP1 spine bank.
